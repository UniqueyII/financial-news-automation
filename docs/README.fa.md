# راهنمای فارسی

این مخزن نسخهٔ عمومی پروژهٔ خلاصه‌سازی اخبار مالی با n8n است. اتصال‌ها و شناسهٔ کانال حذف شده‌اند؛ نسخهٔ اصلی روی سیستم شما تغییری نمی‌کند.

۱. فایل database/schema.sql را در دیتابیس مخصوص اخبار اجرا کنید.
۲. فایل workflows/financial-news.json را وارد n8n کنید و اتصال‌های PostgreSQL، Groq و Telegram را انتخاب کنید.
۳. در Config شناسهٔ مقصد را وارد کنید. ابتدا dryRun=true و autoPublish=false بماند.
۴. پس از بررسی خروجی، برای ارسال واقعی dryRun=false و autoPublish=true کنید و وورک‌فلو را منتشر/فعال کنید.

برای ارسال دستی پیش‌نمایش، فایل reviewed-publisher.json را وارد کنید؛ مقاله را بخوانید و در Config شناسهٔ مقاله، شناسهٔ مقصد و confirmSend=true را مشخص کنید. این مسیر پیام واقعی می‌فرستد و فقط preview را می‌پذیرد. بعد از استفاده confirmSend را false کنید.

اسناد انگلیسی جزئیات نصب، محدودیت‌ها و تست‌ها را توضیح می‌دهند. مدل متن کامل خبر را نمی‌خواند و تضمینی برای صحت تحلیل وجود ندارد. روشن بودن کامپیوتر و سرویس‌ها برای اجرای زمان‌بندی لازم است.

برای انتشار GitHub، محتوای همین پوشه را بارگذاری کنید، نه فایل ZIP و نه خروجی‌های اصلی دارای اطلاعات شخصی. ویدیوی دمو هنوز باید ضبط و لینک آن در README اضافه شود.
